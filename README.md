# QUIZ

Quiz interativo com 11 questões sobre bases de dados científicas.

Alunos: https://quiz-x6f4.onrender.com/

Professor: acrescente `?host=VALOR_DE_ADMIN_KEY` ao endereço. A chave privada fica na variável ADMIN_KEY no painel do Render. Mantenha o link do professor privado.

Render: Python 3, plano Free, build `pip install qrcode[pil]==8.2`, start `python server.py`.

O serviço gratuito pode suspender por inatividade. Abra a sala antes da aula. Partidas e pontuações ficam na memória e são apagadas ao reiniciar o servidor.

Para simulação offline, abra teste.html. Para rede local, instale qrcode[pil] e execute server.py.
